# 游玩与开发指南

## 原版自由巡航

[最初飞机版](https://kinzun.github.io/aircraft-patrol/versions/original/)从秋日湖区起飞。点击 **TAKE FLIGHT**，移动鼠标或使用方向键操纵战机。空格切换追尾、北向俯视和座舱；轻点左键桶滚，长按左键或 Shift 加力。按 F 或点右键发射翼下导弹，四个挂架会自动补弹。低空时飞机会自动拉升。

## 战斗版本操作

| 操作 | 云上奇行 · 战机融合 | 北湖空战 · 像素版和 3D 版 |
| --- | --- | --- |
| 出击 | Enter 或屏幕上的出击按钮 | 点击 TAKE FLIGHT |
| 驾驶 | A、D 横移，W、S 升降，方向键也可用 | 鼠标或方向键控制。追尾和座舱视角调整转弯与俯仰，北向俯视时朝指向的位置飞行 |
| 机动 | Shift 加力，空格快速拉升 | 轻点鼠标左键桶滚，按住左键或 Shift 加力 |
| 视角 | 跟随机组的战斗镜头 | 空格或右上角按钮依次切换追尾、北向俯视和座舱 |
| 武器 | 按住 Z 肩炮，C 熊吼清弹 | F 或鼠标右键发射翼下导弹，按住 Z 连射机炮，C 启动清弹护盾 |
| 六大招 | Q 冰刺、E 雷暴、R 陨石、**F 光束**、V 束缚场、X 冰川 | Q 冰刺、E 雷暴、R 陨石、**B 光束**、V 束缚场、X 冰川 |
| 支援技能 | 1 推进、2 超燃、3 筋斗云、4 鹈鹕吞天嗝 | 1 推进、2 超燃、3 相位驱动、4 风暴脉冲 |
| 声音 | M 或声音按钮 | 右上角 SOUND 按钮，默认静音 |

北湖版的锁定框标出机头前方的空中目标。发射后，对应翼下挂架会空出，稍后自动补弹。触屏上拖动控制方向，屏幕按钮负责机动和导弹；展开 **ARMAMENT** 可以点按技能、开火和查看冷却。

两套玩法都能打破母舰装甲。连续命中会积累姿态压力，母舰失衡时承受额外伤害；触发火力超载后，可以在有限时间内连续使用六大招。

## 构建与回归

每个版本目录都是独立的构建入口。以下命令在仓库根目录执行，替换路径中的版本名即可选择 `original`、`fusion`、`pixel` 或 `3d`。

```sh
cd versions/pixel
npm run build
npm test
npm run serve
```

`npm run build` 使用 Python 3 将脚本和样式内联到当前版本的 `index.html`。`npm test` 先构建，再用 Node.js 执行 `tests/check*.cjs`。本地服务器绑定 `127.0.0.1:8091`；切换预览版本时先用 Ctrl+C 停止当前服务器。

各版的 Chromium 无头浏览器测试覆盖飞行操作与画面。安装方法、运行命令和截图位置见[浏览器测试指南](../qa/README.md)。在仓库根目录运行 `shasum -a 256 -c SHA256SUMS` 可以核对四个构建页面与各自的存档是否一致。

## 从哪里修改

| 想修改的内容 | 版本目录内的源码入口 |
| --- | --- |
| 云上奇行的输入、生命周期和角色 | `src/ui/input.js`、`src/app.js`、`src/render/rider.js` |
| 北湖的飞行手感、相机和地形 | `src/patrol/flight.js`、`src/patrol/world.js` |
| 北湖的战机和座舱 | `src/patrol/airframe.js` 负责翼下导弹与轨迹，像素版也在此绘制战机；3D 机体位于 `src/patrol/jet-view.js`，座舱位于 `src/patrol/cockpit.js` |
| 北湖的输入、技能面板和空战坐标 | `src/patrol/main.js`、`src/patrol/combat-hud.js`、`src/patrol/combat.js` |
| 伤害、敌群、母舰与特效 | `src/simulation/` 保存规则，`src/render/` 和 `src/effects/` 消费战斗状态与事件，`src/audio/` 合成声音 |

自由巡航原版的打包入口见[原版开发说明](../versions/original/README.md)。三个战斗版新增浏览器脚本时，在该版本的 `scripts/browser-scripts.json` 中把依赖排在使用方之前。修改完源码后重新构建，并打开生成的 HTML 实际飞行一局；修改共用玩法时，在涉及的每个版本分别运行测试。
