# PATROL · 北湖空战

直接打开根目录 `index.html`。飞机在原 PATROL 的秋日湖区自由飞行，追尾、北向俯视和座舱共用同一套战斗状态。原游戏的六种技能、蜂群编队、母舰、破甲、失衡和超载接入了这架飞机。画面和声音均在本地生成。

| 操作 | 效果 |
| --- | --- |
| 移动鼠标或方向键 | 转弯、爬升与俯冲；俯视时朝指向的位置飞行 |
| 轻点 / 按住左键 | 桶滚 / 加力 |
| 空格 | 追尾 → 俯视 → 座舱 |
| F 或右键 | 发射翼下导弹。方框表示可锁定的空中目标，无锁定时沿机头发射 |
| 按住 Z / 按 C | 机炮连射 / 清弹护盾 |
| Q / E / R / B / V / X | 冰刺、雷暴、陨石、光束、束缚场、冰川 |
| 1 / 2 / 3 / 4 | 推进、超燃、相位驱动、风暴脉冲 |

触屏拖动控制方向，屏幕按钮控制视角、导弹、加力与桶滚。打开 ARMAMENT 可点按其余装备并查看冷却。默认静音，SOUND 开启引擎与战斗音效。

## 开发

`npm run build` 从 `scripts/browser-scripts.json` 指定的源码生成离线页面。运行 `npm test` 构建并执行回归测试；`npm run serve` 提供本机预览。`src/patrol/` 包含飞行、地形、座舱与空战适配。战斗规则、敌机、原生技能与特效分别位于 `src/simulation/`、`src/render/`、`src/effects/` 和 `vendor/reference-six/`。原始骑行页见 [wing-rider.html](../../history/archive/wing-rider.html)。

## 战斗

僚机分批进入空域。机身周围的锁定框指示翼下导弹目标，转向或山脊遮挡会影响锁定。机炮和六种技能沿机头方向作战，命中后可恢复部分机体耐久。

母舰耐久为 900。用冰刺、雷暴和束缚场积累姿态压力，失衡时用陨石或光束追击。失衡窗口持续 2.2 秒，伤害提高至 1.75 倍。首次打破一个装甲阶段的姿态会触发火力超载，六大招可在超载期间连续使用。母舰范围攻击、分段破甲、连爆、镜头反馈与音效沿用原战斗模块。
